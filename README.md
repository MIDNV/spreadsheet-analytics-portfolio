# 🎮 MIDNVRC Studios — Executive Games Analytics Dashboard

> **Interactive Google Sheets analytics suite tracking multi-platform revenue, user engagement, player retention, and game health matrices for MIDNVRC Studios.**
> Demonstrating scalable data architecture, locale standardization, and dynamic executive reporting.

---

## 📌 Overview

This project provides an end-to-end business intelligence solution designed for game studios to evaluate portfolio performance across **PC, Console, iOS, and Android** platforms.

By processing raw transactional performance logs, the dashboard delivers real-time monetization tracking, engagement analytics, and conversion health indicators to support data-driven game management and C-level decision-making.

---

## 🛠️ Key Technical Competencies & Features

* **Advanced Formula Logic:** Utilizes `SUMIFS`, `AVERAGEIFS`, `UNIQUE`, `IF`, `AVERAGE`, and wildcard pattern matching (`*`) for precise aggregation across variable criteria.


* **Dynamic UX Interactivity:** Integrated Data Validation drop-down controls directly linked to dynamic KPI models for instant, real-time platform filtering.


* **Executive Data Visualization:** Corporate-grade Column Charts and Donut Charts engineered for quick executive assessment and board-level reporting.


* **Data Standardization & Locale Error Handling:** Resolved complex `#VALUE!` syntax errors by standardizing decimal separators and unifying heterogeneous numeric data formats.


---

## 📊 Core Metrics & KPIs Tracked

| Category | Metrics Tracked |
| --- | --- |
| **Monetization** | Total Revenue (IAP + Ad Revenue), Gross Revenue (IAP), Ad Revenue, and ARPU (Average Revenue Per User)  |


| **User Engagement** | Daily Active Users (DAU) and Monthly Active Users (MAU)  |


| **Conversion & Health** | Average Conversion Rate (%) and Player Retention Rates (D1 & D7 Retention) |

---

## 📂 Dashboard Architecture

The workbook is structured into dedicated functional layers to ensure modularity and ease of maintenance:

* **`01_Overview`**: Project documentation, system architecture, data definitions, and tech stack overview.


* **`02_Executive_KPIs`**: High-level C-suite dashboard featuring dynamic KPI cards, top-line performance metrics, and interactive platform filters.


* **`03_Game_Performance`**: Deep-dive analytical view focusing on revenue attribution across PC, Console, iOS, and Android alongside game health matrices.


* **`04_Raw_Data`**: Clean, standardized data repository housing daily performance logs across titles, regions, and distribution platforms.
